# Basic HTML Website

**Project URL:** https://roadmap.sh/projects/basic-html-website

A multi-page basic HTML website built as part of the [roadmap.sh Frontend Developer track](https://roadmap.sh/projects/basic-html-website). This project focuses on semantic HTML structure, multi-page navigation, SEO meta tags, and foundational web layout.

## Pages

- **Home (`index.html`)** — Overview of projects, work experience, education, and teacher reviews.
- **Projects (`projects.html`)** — List of completed and upcoming projects.
- **Articles (`articles.html`)** — Articles and blog posts section.
- **Contact (`contact.html`)** — Contact information and form.

## Features

- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `aside`, `footer`)
- SEO meta tags (`description`, `keywords`, `author`, `viewport`)
- Consistent navigation bar across all pages
- Custom styling with CSS (`style.css`) and Google Fonts (`Barlow Condensed`)
